## What this is

The first **bedrock** change of the FQCN arc: `dazzle_lib`'s four ladder types gained the nucleus/framing split, ranks-as-addresses (`level_at`), declared subtypes, self-naming anonymous rungs, christening, and `shift_from` — plus, one layer up, the one-node value alias making `dz :.level` and `dz level` a single validated value. Everything downstream sits on these types, so this checklist leans hard on **edge cases and composition chains** — including two pre-seeded suspicions the automated vectors do NOT cover (Section 4). Run by a human or the tester agent; bedrock probes are pure Python (no state); CLI probes use an isolated config.

## High-Value Verification (~5 minutes)

### HV.1 — The user's thesis, end to end (bedrock)
Validates: ranks are bidirectional addresses.
- [ ] **Steps** (any shell): `python -c "from dazzle_lib.groupable import Groupable; from dazzle_lib.continuum import Continuum; c=Continuum.from_groupable(Groupable('remove','add','membership')); print(c.level_at(1), c.level_at(-1), c.nucleus().label)"`
- [ ] **Expected:** `add remove membership`
- [ ] **Why this matters:** this IS the design — if the +1/−1/nucleus triple is wrong, everything above it inherits the lie.

### HV.2 — The level alias, both directions, validated (CLI)
- [ ] **Steps** (isolated config set per Prerequisites): `dz :.level=bogus` → then `dz :.level=kit` → `dz level` → `dz :.level`
- [ ] **Expected:** exit 2 with the level-choices error (NO write anywhere); then exit 0, and BOTH reads print `kit` (each fiber-spelled op echoes `-> dz.level (the node's value)`).
- [ ] **Why this matters:** the F2 fix — a silent inert shadow key was the sweep's worst finding.

### HV.3 — Anonymous rung lifecycle (bedrock)
- [ ] **Steps:** `python -c "from dazzle_lib.continuum import Continuum; c=Continuum('v',ranks={'a':-1,'b':1}); c2=c.densify_between('a','b'); print('0' in c2.ranks); c3=c2.rename_level('0','mid'); print(c3.rank('mid'), '0' in c3.ranks)"`
- [ ] **Expected:** `True` then `0 False` — self-named at the mediant, christening moves the key and keeps the rank.

### HV.4 — Shift makes room; the invariant is untouchable
- [ ] **Steps:** `python -c "from dazzle_lib.continuum import Continuum; c=Continuum('v',ranks={'d':0,'t':1,'g':2,'x':3}); c2,r=c.shift_from(3,by=1); print(c2.rank('x'), r); c.shift_from(0,by=1)"`
- [ ] **Expected:** `4 {'x': (Fraction(3, 1), Fraction(4, 1))}` then a `ContinuumError` naming the invariant seat.

### HV.5 — Subtypes reject the lie
- [ ] **Steps:** `python -c "from dazzle_lib.continuum import Continuum; Continuum('m',ranks={'add':0,'remove':-1},subtype='full')"`
- [ ] **Expected:** `ContinuumError` ("lacks reaches on BOTH sides") — the exact encoding C1 exists to make visible.

### HV.6 — Downstream unbroken (the ripple smoke)
- [ ] **Steps** (cross-shell, dz only): `dz list` · `dz info find` · `dz -v list` · `dz version`
- [ ] **Expected:** all render normally, exit 0 — the bedrock change is invisible where it should be.
